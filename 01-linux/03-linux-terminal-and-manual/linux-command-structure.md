# Linux Command Structure

## Overview
**Linux Command Structure** covers how a command is built: `command [options] [arguments]`. Options (usually prefixed with `-` or `--`) modify a command's behaviour, while arguments tell the command what to act on.

Recognising this pattern makes unfamiliar commands far easier to read, since almost every Linux tool follows the same basic shape.

---

## Key Learnings
- A command's structure is: **command → options → arguments**
- Options can usually be combined (e.g. `ls -la`)
- Long options use `--` (e.g. `--help`) while short options use `-` (e.g. `-h`)
- Order of arguments can matter depending on the command

---

## Reflection
Once I recognised the command / options / arguments pattern, reading new commands stopped feeling random — I could break them down piece by piece instead of memorising each one.
