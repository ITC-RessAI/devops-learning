# Managing Files and Directories

## Overview
**Managing Files and Directories** covers the core commands for creating, copying, moving, and deleting files and folders. These are the everyday building blocks of working in a Linux terminal.

---

## Key Learnings
- `mkdir` creates directories, `touch` creates empty files
- `cp` copies, `mv` moves or renames, `rm` deletes
- `rm -r` is required to delete directories and their contents
- Deleted files via `rm` don't go to a recycle bin — they're gone

---

## Commands Practised
### `mkdir` – Make Directory
Creates a new directory.

### `touch` – Create File
Creates a new empty file or updates a file's timestamp.

### `cp` – Copy
Copies files or directories (`-r` for recursive copy of directories).

### `mv` – Move / Rename
Moves a file to a new location, or renames it if the destination is in the same directory.

### `rm` – Remove
Deletes files (`-r` for directories, `-f` to force without confirmation).
