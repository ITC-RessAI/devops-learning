# Hostnamectl

## Overview
**hostnamectl** views and manages a system's hostname — the human-readable name a machine identifies itself by on a network.

---

## Key Learnings
- `hostnamectl` shows the current hostname along with OS and kernel details
- Hostnames can be static, transient, or pretty (display-friendly)
- Changing a hostname doesn't require editing config files directly

---

## Commands Practised
### `hostnamectl`
Displays the system's current hostname and related system info.

### `hostnamectl set-hostname <name>`
Sets a new hostname for the system.

---

## Reflection
`hostnamectl` was a small command but a useful one — I hadn't realised how much system info it surfaces in one place.
