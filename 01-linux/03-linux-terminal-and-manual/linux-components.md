# Linux Components

## Overview
**Linux Components** covers the core building blocks that make up a Linux system: the **kernel**, the **shell**, and the **user space** tools that sit on top of them. The kernel manages hardware, memory, and processes, while the shell acts as the interface between the user and the kernel, interpreting the commands typed into the terminal.

Understanding how these pieces fit together explains *why* Linux behaves the way it does, rather than just memorising commands in isolation.

---

## Key Learnings
- The **kernel** is the core of the OS — it manages hardware, memory, and processes
- The **shell** is the command-line interpreter that sits between the user and the kernel
- **User space** contains the applications and utilities that run on top of the kernel
- Everything in Linux, including devices, is treated as a file
