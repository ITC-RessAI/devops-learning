# AWS Network Environment Setup

## Overview
Setting up an **AWS network environment** gave me a real network to practise against, instead of just a single isolated machine — building a VPC-backed EC2 instance to explore interfaces, hostnames, and DNS in a realistic setup.

---

## Key Learnings
- A cloud VM still relies on the same underlying Linux networking concepts as any local machine
- Security groups and network configuration sit outside the OS but directly affect what's reachable
- Practising networking on AWS ties Linux fundamentals directly to real infrastructure

---

## Reflection
Doing the networking module on an actual AWS instance rather than a local VM made the difference between local and public networking much more tangible.
