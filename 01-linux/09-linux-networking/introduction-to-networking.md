# Introduction to Networking

## Overview
**Introduction to Networking** covers the core concepts behind how Linux machines communicate: IP addresses, network interfaces, and the basic tools used to inspect and test connectivity.

---

## Key Learnings
- Every network-connected device has at least one network interface
- IP addresses identify a device on a network
- Basic connectivity tools (`ping`, `ip`) are essential for diagnosing network issues
- Networking concepts apply the same way locally and in the cloud

---

## Commands Practised
### `ip a`
Displays all network interfaces and their assigned IP addresses.

### `ping <host>`
Tests connectivity to another host on the network.

---

## Reflection
Running `ip a` and `ping` against real hosts made networking concepts feel a lot less theoretical.
