# Vim

## Overview
**Vim** is a modal text editor built for the terminal — instead of always typing directly into the document, it has distinct modes for navigating, editing, and issuing commands. It's the default editor on most Linux systems, so being able to use it, even at a basic level, is essential.

---

## Key Learnings
- Vim opens in **Normal mode** by default, not Insert mode
- Files are edited entirely from the keyboard, with no mouse needed
- Changes must be explicitly saved and the editor explicitly exited
- Vim is available on almost every Linux system by default, unlike GUI editors

---

## Commands Practised
### `vim <file>`
Opens a file in Vim for editing.

### `:wq`
Saves changes and exits.

### `:q!`
Exits without saving changes.

---

## Reflection
Vim felt awkward the first few times, mostly because of the mode-switching, but it's clearly worth pushing through since it's unavoidable when editing config files on a remote server.
