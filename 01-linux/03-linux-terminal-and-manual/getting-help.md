# Getting Help

## Overview
**Getting Help** covers how to find documentation for a command without leaving the terminal. `man` and `--help` are the two main tools — `man` gives a full manual page, while `--help` gives a quick summary of flags and usage.

Being comfortable reading manual pages makes it possible to learn any new command independently.

---

## Key Learnings
- `man <command>` opens the full manual page for a command
- `<command> --help` gives a quick usage summary
- Manual pages are structured consistently: NAME, SYNOPSIS, DESCRIPTION, OPTIONS
- Reading documentation is a core Linux skill, not a fallback

---

## Commands Practised
### `man` – Manual Pages
Displays full documentation for a given command, including all available options.

### `--help`
A quick flag most commands support, showing a short usage summary.

---

## Reflection
Getting comfortable with `man` pages early made me a lot less dependent on searching online for basic command usage.
